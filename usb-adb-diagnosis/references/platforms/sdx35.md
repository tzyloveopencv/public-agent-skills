# SDX35 适配

使用条件：用户或实际设备资料明确确认 SDX35。型号、固件、内核、USB composition、Host 与 AT/UART 端口由项目配置和现场识别决定。

优先检查项目已有 USB 配置脚本、adbd 启动方式、DWC3 厂商分支与已采集日志。不同产品/版本可能使用不同配置路径、端点分配与授权流程，不能统一写死 AT 命令、UDC 名称、寄存器地址或服务名。

若开启 ADB 后整个复合设备枚举失败，对比前后 composition、描述符、端点请求和绑定错误，再根据该内核实际端点能力验证资源假设。端点限制不能预设为所有 SDX35 的同一数值。

目前没有导入经过原始证据复核的历史根因案例。后续案例至少记录平台/版本、触发条件、证据位置、已证实结论、尚存限制；旧工单实验补丁保持假设身份。
